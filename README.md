# MR.MAHMOOD — حاسبة المخاطر وسجل التداول (نسخة قابلة للتثبيت)

**آخر تحديث:** يشمل الآن **مزامنة سحابية حقيقية بين الأجهزة** (تسجيل دخول بالبريد وكلمة المرور، عبر Firebase) بجانب: حسابات متعددة مستقلة، الملاحظات الملوّنة متعددة المرفقات، حدود الخسارة اليومية/الأسبوعية، الصفقات المفتوحة مع صور قبل/بعد، جلسات فوركس مباشرة، ودعم كامل للعربية/الإنجليزية والوضع الليلي/النهاري.

## ⚠️ شرط أساسي
ميزة "التثبيت" **والمزامنة السحابية معاً** لا تعملان إذا فتحت `index.html` مباشرة بالنقر المزدوج من جهازك.
يجب استضافة هذه الملفات على رابط حقيقي بتقنية HTTPS أولاً (GitHub Pages يوفّرها تلقائياً) — وهذا مجاني وسهل.

## ☁️ ملاحظة عن المزامنة السحابية
إعدادات Firebase (`firebaseConfig`) مضمّنة بالفعل داخل `index.html` ولا تحتاج أي إعداد إضافي منك — فقط ارفع الملفات وافتح الرابط من كل أجهزتك، وسجّل دخولك بنفس البريد وكلمة المرور على كل جهاز.

## 🚀 أسهل طريقة استضافة مجانية: GitHub Pages

1. أنشئ حساباً مجانياً على github.com إن لم يكن لديك واحد.
2. أنشئ مستودعاً (Repository) جديداً، مثلاً باسم `mr-mahmood-app`.
3. ارفع الملفات الأربعة كلها إلى المستودع:
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-512-maskable.png`
4. اذهب إلى Settings > Pages في المستودع، واختر النشر من الفرع الرئيسي (main / root).
5. بعد دقيقة أو دقيقتين، سيعطيك GitHub رابطاً مثل:
   `https://username.github.io/mr-mahmood-app/`
6. افتح هذا الرابط من هاتفك الأندرويد (Chrome) أو جهاز الويندوز (Chrome/Edge).

## 📲 التثبيت على أندرويد
- افتح الرابط في Chrome.
- ستظهر رسالة "إضافة إلى الشاشة الرئيسية" تلقائياً، أو اضغط على زر
  "تثبيت التطبيق الآن" داخل صفحة الإعدادات في التطبيق نفسه.
- ستظهر أيقونة التطبيق على شاشتك الرئيسية وتفتح كتطبيق مستقل.

## 🖥️ التثبيت على ويندوز
- افتح الرابط في Chrome أو Edge.
- ستلاحظ أيقونة تثبيت (⊕ أو شاشة صغيرة) في شريط العنوان، أو استخدم
  زر "تثبيت التطبيق الآن" من صفحة الإعدادات.
- سيُضاف التطبيق إلى قائمة ابدأ ويفتح في نافذته الخاصة.

## بدائل استضافة مجانية أخرى
- Netlify Drop (netlify.com/drop) — اسحب مجلد الملفات وأفلته، يعطيك رابطاً فوراً بدون حساب.
- Vercel، Cloudflare Pages — خيارات مجانية مشابهة.

## ملاحظات
- بعد الاستضافة، التخزين المحلي (حفظ صفقاتك تلقائياً) سيعمل بثبات تام —
  لأن مشاكل `file://` التي واجهتها سابقاً لا تحدث مع الاستضافة الحقيقية.
- ميزة "ربط ملف حفظ تلقائي" من الإعدادات تبقى متاحة أيضاً كطبقة حماية إضافية.
- التطبيق يعمل بدون إنترنت بعد أول فتح ناجح، بفضل service-worker.js.
